def memoize_tree(node, cache=None):
    if cache is None:
        cache = {}
    if node is None:
        return 0
    
    # Prune evaluated sub-branches
    if node.id in cache:
        return cache[node.id]
        
    cache[node.id] = node.val + max(
        memoize_tree(node.left, cache),
        memoize_tree(node.right, cache)
    )
    return cache[node.id]

Unit 4.3: Memoization and Dynamic Tree Pruning

Lesson 3 of 5

Lesson Summary

In this module we explore how naive recursion across hierarchical tree configurations can cause severe exponential call overheads. By anchoring a cache dictionary to recurring node identification keys, we bypass recalculating already computed branch payloads. Dynamic tree pruning then strips redundant subtree operations before invocation.

timer
Time Complexity O(V + E)

Reduced from naive worst-case branching factor of O(2ⁿ).

memory
Space Complexity O(depth + N)

Recursion stack bound plus explicit memoized dictionary footprint.

Standard Recursive vs Memoized Pattern

from functools import lru_cache

@lru_cache(maxsize=None)
def pruned_subtree_weight(node_id):
    node = get_node(node_id)
    if not node or node.is_pruned:
        return 0
    return node.val + sum(pruned_subtree_weight(c.id) for c in node.children)
